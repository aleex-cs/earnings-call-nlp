# Assets

Este directorio contiene imágenes y assets para el proyecto.

## Capturas del Dashboard

Para añadir capturas del dashboard:

1. **Ejecutar el dashboard**:
   ```bash
   streamlit run app.py
   ```

2. **Tomar capturas** de:
   - Página principal con métricas
   - Análisis temporal con gráficos
   - Sistema de alertas
   - Comparación entre empresas

3. **Guardar capturas** en este directorio:
   - `dashboard_main.png` - Vista principal
   - `dashboard_analysis.png` - Análisis detallado
   - `dashboard_alerts.png` - Sistema de alertas

4. **Actualizar README.md** con las imágenes:
   ```markdown
   ![Dashboard Principal](assets/dashboard_main.png)
   ```

## Logo y Branding

Si tienes un logo del proyecto, guárdalo aquí como:
- `logo.png` - Logo principal
- `logo_dark.png` - Logo para modo oscuro
- `favicon.ico` - Favicon para el dashboard
